# maven-electronics-sales-dashboard-excel
Interactive Sales Dashboard built using Excel, Power Query, Power Pivot, DAX, and Pivot Charts.
## Business Scenario

It's 4:00 PM on a Friday.

The VP of Sales urgently requests an executive report for Monday morning's regional sales meeting.

The report must provide insights into:

Monthly Revenue
Monthly Orders
Product Category Performance
Country-wise Sales

The challenge?

Business data is spread across multiple sources, the data is over the place – SQL servers, CSV files, even static PDFs – and she needs it first thing Monday morning., requiring extraction, transformation, modeling, and visualization before meaningful insights can be delivered.

## Project Objective

Build an interactive Excel dashboard that enables regional sales managers to monitor revenue trends and product performance while supporting data-driven decision-making.

## Tools Used
Microsoft Excel
Power Query
Power Pivot
DAX
Pivot Tables
Pivot Charts
Slicers
Data Modeling
